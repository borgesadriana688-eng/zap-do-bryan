# 💬 Zap do Bryan - seu WhatsApp na Vercel

App de chat em tempo real (sala #Geral, #Jogos, #RP) feito em um único HTML.
Hospedagem: **Vercel (grátis)** · Banco + tempo real: **Supabase (grátis)**

---

## Passo 1 - Criar o Supabase (grátis, ~5 min)

1. Acesse **https://supabase.com** e crie uma conta (pode entrar com GitHub)
2. Clique em **New project** → nome: `zapdobryan` → escolha uma senha → Create
3. Aguarde 2 min enquanto o banco é criado
4. No menu lateral: **SQL Editor** → **New query** → cole o código abaixo → **Run**:

```sql
create table messages (
  id bigint generated by default as identity primary key,
  room text not null default 'geral',
  name text not null,
  text text not null,
  created_at timestamptz not null default now()
);

alter table messages enable row level security;

-- qualquer um pode LER as mensagens (anon)
create policy "leitura publica"
  on messages for select
  to anon
  using (true);

-- qualquer um pode ENVIAR mensagens (anon)
create policy "escrita publica"
  on messages for insert
  to anon
  with check (true);
```

5. No menu: **Project Settings (⚙️) → API**. Você vai ver:
   - **Project URL** → copie
   - **anon public** → copie

## Passo 2 - Colar as chaves no app

Abra o arquivo `index.html` e procure no final:

```
const SUPABASE_URL  = "COLE_A_URL_DO_SEU_SUPABASE_AQUI";
const SUPABASE_ANON = "COLE_A_CHAVE_ANON_AQUI";
```

Troque pelas duas coisas que você copiou. Salve.
(Essas duas chaves são públicas por natureza, não é a senha do banco - tranquilo.)

## Passo 3 - Subir pro GitHub

1. Crie conta no **https://github.com** (se não tiver)
2. Crie um repositório novo: **New repository** → nome: `zap-do-bryan` → **Public** → Create
3. **Add file → Upload files** → arraste o `index.html` e este README → **Commit changes**

## Passo 4 - Publicar na Vercel (grátis)

1. Acesse **https://vercel.com** e entre com sua conta **GitHub**
2. **Add New → Project** → escolha o repositório `zap-do-bryan`
3. Framework Preset: deixe **Other** (é site estático, não mexe em nada)
4. Clique em **Deploy** → pronto em ~30 segundos
5. A Vercel te dá um link tipo `https://zap-do-bryan.vercel.app`

**Esse link é o SEU WhatsApp.** Manda pra quem você quiser, abre no celular,
entra com um nome e conversa em tempo real. Funciona em Android, iPhone e PC.

---

## Detalhes

- **Grupos**: Geral, Jogos e RP. Pra criar outro, mude o `<select id="room-select">`
  no HTML e use o mesmo nome no Supabase (o filtro cria na hora).
- **Testar local**: só abrir o `index.html` no navegador depois de colocar as chaves.
- **Limites do grátis**: Supabase free aguenta tranquilo um grupo de amigos
  (500 MB de banco, tempo real incluído).
- **Privacidade**: como não tem login com senha, é um chat aberto pra quem tem
  o link. Se quiser senha/trancar, dá pra evoluir depois com o Auth do Supabase.
